# Mini-pam-programme
PowerShell + Microsoft Graph scripts for Entra PIM assignment reporting and access review summaries

## Scripts

- `Get-PIMReport.ps1` — reports on active and eligible PIM role assignments via Microsoft Graph, flagging assignments active beyond a set threshold.
- `Get-AccessReviewSummary.ps1` — pulls Entra Access Review outcomes via Microsoft Graph and summarises decisions, justifications, and reviewers.
